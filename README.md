Device configuration for Xiaomi Pad 5 Pro 5G
=========================================

The Xiaomi Pad 5 Pro 5G (codenamed _"enuma"_) is a high-end tablet from Xiaomi.

It was announced in August 2021. The Wi-Fi-only sibling is codenamed _"elish"_.

## Device specifications

Basic   | Spec Sheet
-------:|:-------------------------
CPU     | Octa-core (1x3.2 GHz Kryo 585 & 3x2.42 GHz Kryo 585 & 4x1.80 GHz Kryo 585)
Chipset | Qualcomm SM8250-AC Snapdragon 870 5G
GPU     | Adreno 650
Memory  | 6/8 GB LPDDR5 RAM
Shipped Android Version | 11.0 (MIUI 12.5)
Storage | 128/256 GB (UFS 3.1)
Battery | Non-removable Li-Po 8600 mAh
Display | 1600 x 2560 pixels, 11.0 inches (~275 ppi), IPS LCD, 120 Hz
Camera  | 50 MP wide + 5 MP depth, 8 MP selfie
Connectivity | 5G Sub-6, Wi-Fi 6, Bluetooth 5.2, USB Type-C
Model   | M2105K81C
