The Xiaomi Pad 5 Pro 5G (codenamed _"enuma"_) is a high-end tablet from Xiaomi.

## Device specifications

| Basic                   | Spec                                                        |
| -----------------------:|:----------------------------------------------------------- |
| SoC                     | Qualcomm SM8250-AC Snapdragon 870 5G (7 nm)                 |
| CPU                     | Octa-core (1x3.2 GHz Kryo 585 & 3x2.42 GHz Kryo 585 & 4x1.80 GHz Kryo 585) |
| GPU                     | Adreno 650                                                  |
| Memory                  | 8 GB RAM (LPDDR5)                                           |
| Shipped Android version | 11.0 with MIUI 12.5                                         |
| Storage                 | 256 GB (UFS 3.1)                                            |
| Battery                 | Non-removable Li-Po 8600 mAh                                |
| Display                 | 1600 x 2560 pixels, 11.0 inches                             |
| Cameras                 | 50 MP (main), 5 MP (depth), 8 MP (front)                    |
